Manage API keys

2. Authenticate

Send the API key in the request header. It is not part of the URL.

X-API-Key: <your-api-key>

The server environment variable is EARN_PROXY_INTERNAL_API_KEY. Never paste the real value into a browser URL or source repository.

3. Choose a response format

Text is easiest for line-based consumers; JSON includes safe metadata.

Raw text

One proxy per line, ready for import.

curl -fsS -H "X-API-Key: $EARN_PROXY_API_KEY" "{{ canonical_endpoint }}"

JSON

Add ?format=json for status, protocol, and endpoint fields.

curl -fsS -H "X-API-Key: $EARN_PROXY_API_KEY" "{{ canonical_endpoint }}?format=json"
